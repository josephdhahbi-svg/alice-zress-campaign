Build availability

This development preview is committed on a GitHub branch. The links work when these files are served together; GitHub source-preview pages are not the deployed game.

Available in this branch: Alice Elder Eye encounter, Vesper Archive, original Alice character creator. Future campaigns remain catalogs, not playable builds.

Save boundaries

Alice's playtest uses moonveil-alice-elder-eye-playtest-v1. Vesper's archive uses moonveil-vesper-archive-v1. The original Alice creator uses elder-eye-save-v2.

This launcher does not merge saves or grant unearned relics. Device-local saves are not synchronized with ChatGPT, GitHub, or a backend. Export save files before clearing browser data. Local saves can differ between file://, localhost and a deployed website because they are different browser storage origins.
