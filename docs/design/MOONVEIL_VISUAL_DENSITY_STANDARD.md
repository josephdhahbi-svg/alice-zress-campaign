# Moonveil Visual Density and Eye-Comfort Standard

User requirement: no sparse black-and-white presentations. All playable scenes should be richly illustrated, visually organized, and color-coded with eye-friendly muted navy/slate/violet surfaces rather than harsh pure black/white.

## Consistent semantic colors
- BLUE (#478DFF): heroic/good NPCs and factions.
- RED (#F16B78): villainous/hostile NPCs and factions.
- GREEN (#48C99A): neutral/morally mixed NPCs and factions.
- PURPLE (#B99AFF): magic, spells, Netherese mysteries.
- GOLD (#F4C66B): artifacts, treasure, quest rewards.
- CYAN (#64C8DF): navigation, routes, discoveries.
Always pair colors with text labels and symbols for accessibility; distinguish character moral classification from temporary hostility and faction standing.

## Required scene layout
1. Header and vivid wide cinematic establishing image.
2. Current verified character stats, HP, inventory, location, time/sequence, mission, and unresolved conditions.
3. Four distinct photorealistic story panels above one full-width decision panel.
4. A legible colored tactical map with grid, legend, arrows, hazards, approximate/verified scale note.
5. Character portraits and moral-role badges.
6. Quests, journal, faction relations, inventory, magic, loot, codex, timeline, travel route, world events and lore; show verified/unknown/pending explicitly.
7. Five clickable decisions in fixed order: Lawful Good, Neutral Good, Chaotic Good, Utility, Action. Autopilot defaults to compassionate heroic completionist action; user can override.
8. Clear distinction between published D&D source, homebrew adaptation, proposed content and earned gameplay state.
9. Fast-loading visual composition: avoid repetitive duplicate images, prioritize 4 story images and relevant portraits, use compact panels for extra detail.
