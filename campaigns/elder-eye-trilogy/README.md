# Elder Eye Trilogy — Working Headquarters

**ACTIVE PRIORITY:** First trilogy only.

This folder is the organizational headquarters for the foundational Elder Eye Trilogy. Until this trilogy is structurally complete, later Underdark/Abyss/Avernus material is context only and must not overwrite its decisions.

## Trilogy
1. **That Which Lurks**
2. **The Labyrinth of the Elder Eye**
3. **The Return of the Avatar of Ghaunador**

## Core conflict
The trilogy establishes the historical/divine foundation behind the later Alice Z'ress campaign:
- **Eilistraee** — heroic moral center: freedom, mercy, song, dance, moonlight and hope.
- **Ghaunadaur / the Elder Eye** — active antagonist/divine threat.
- **Lolth** — independent major antagonist and drow political-divine power.
- Other gods, factions and historical figures enter only after chronology/geography verification.

## Seven-theme design language
For the Eilistraee/Chosen side, preserve:
**Sword + Song + Dance + Moonlight + Mercy + Freedom + Hope.**

## Working rule: everything connects
No isolated lists. Every scene, character choice, item, skill, feat, proficiency, instrument, spell, relationship, faction, location, ritual and later transformation must cross-reference the event that caused it.
