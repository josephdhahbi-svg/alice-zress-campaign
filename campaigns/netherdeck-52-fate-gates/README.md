# THE NETHERDECK — The 52 Fate Gates

Campaign ID: `MEGA-001`

A connected level 1–20 Moonveil megadungeon using 52 selected card themes from the larger card pool presented in *The Book of Many Things*. This project is separate from the repository's earlier custom 54-card dungeon scaffold.

**Current production state: PLANNED.** The 52 sequence is registered, but keyed maps and combat simulations have not yet been completed.

Files:
- `master-register.json` — authoritative 52-dungeon sequence and status.
- `ADMIN-AUDIT.md` — numbering, categories, source labels, production gates, completeness audit.
- `CHARACTER-ROSTER.md` — 15 named prototypes + 36-build class lab.
- `combat-log-template.json` — exact data fields required for every combat.
- `MAPS-AND-ITEMS.md` — map status, reward status, corrupted-item progression.

Core progression: one dungeon unlocks the next through a numbered Fate Gate. DNG-052 is the Living Deck finale.
