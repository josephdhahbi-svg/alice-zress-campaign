## Integrity rules
- Never fabricate a played result merely to fill the register.
- A dungeon moves PLANNED -> BUILT -> SIMULATED -> AUTOPSIED -> CANONIZED only after the corresponding work exists.
- Preserve raw d20 and damage/healing dice rolls for meaningful combat actions.
- Track spell casts individually so damage, control, prevention, healing, concentration, action economy, resource efficiency, target count, overkill, boss value, and failure rate can be analyzed.
- Keep theoretical expected value separate from observed dice results.
- Every character sheet is cumulative: HP/resources reset only when the rules permit; earned items, conditions, choices, deaths, relationships, milestones, and quest consequences carry forward.
- Use the 2024 PHB rules baseline for the 12 core classes. Non-PHB material must remain explicitly labeled.
- Card-source meaning and Moonveil adaptation remain separate fields.
