# MEGA-002 — Cast, Dialogue & Artifact Web

Status: **ROUGH DRAFT / PLAYTEST CONTENT**
Campaign: Sword Coast Five — The Second Deck
Route: Baldur's Gate -> Sword Coast -> coastal ruins -> trade-road descent -> Underdark

## Design law: everything leaves evidence
The Second Deck mystery is reconstructed through people and physical culture. Each dungeon should contain several connected evidence types rather than one exposition dump:
- SCR = scroll
- PNT = painting/mural
- COM = comic/illustrated serial
- RUN = ruin/archaeological site
- REL = relic
- BOK = book/journal/ledger
- SONG = song/music fragment
- MAP = map/cartographic evidence
- INS = inscription
- OBJ = ordinary object with historical context

Evidence has provenance, author/creator, approximate era only when verified, current holder, reliability, interpretation, contradiction links, quest unlocks, and future callbacks. Never invent an exact Forgotten Realms date just to complete a field.

# Five-PC dialogue engine
Each major scene gives all five a distinct viewpoint before the player's nine moral responses.

Aurelia/Tank: "Who gets hurt if we're wrong?"
Amara/Healer: "Who has already been hurt, and what do they need?"
Elara/Melee: "What happens when the plan meets resistance?"
Seraphine/Ranged: "What are we missing outside the room?"
Ilyra/Utility: "What does the evidence actually prove?"

Their lines evolve. Repeated failure, betrayal, mercy, professional success and discoveries can change these default questions.

# Artifact relationship rules
1. Scroll = direct narrative chain.
2. Painting = visual evidence and hidden/overpainted history.
3. Comic = public mythology, propaganda, prediction or reactive reality; reliability must be tested.
4. Ruin = physical archaeological evidence that can confirm or refute texts.
5. Relic = interactive/mechanical evidence and later gameplay utility.
6. Book = deep context, ledgers, scholarship and contradictory testimony.
7. Song = memory, navigation, communication and culture.
8. Map = spatial truth that updates when the party changes the world.
No artifact type is automatically more truthful than another.

# Treasure connection law
Every major treasure gets:
origin -> prior clue -> acquisition condition -> immediate function -> later noncombat use -> later combat use if any -> NPC/faction interest -> morality consequence -> possible upgrade/purification -> final-campaign callback.

# Character-development connections
Aurelia and Deren debate institutional authority across multiple dungeons.
Amara and Caldus develop an ethics-of-restoration thread.
Elara and Tavia connect soldier practicality to engineering/logistics.
Seraphine and Lysa connect navigation, ecology and musical signals.
Ilyra, Sella and Pell form an evidence/reliability triangle: text vs image vs physical/magical proof.
Mara represents the civilians affected by every grand decision.
Vhaera tests whether the party treats Underdark communities as people with agency rather than scenery.
Brikk tests privacy versus useful technology.
Rook tests preservation versus ownership/profit.
The Inkless Courier tests whether information itself is manipulating the party.

# Administration requirement
Every artifact and NPC receives stable IDs and provenance. Every dialogue consequence links to MOR/DEC/REL/OUT IDs. Every side quest must point to at least one later main quest. Every important treasure must have at least one later use. Every dungeon must contain evidence that can be cross-checked rather than accepted blindly.
